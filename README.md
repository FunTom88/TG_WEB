# TG_WEB

Установщик Telegram WEB Proxy для **Ubuntu Server 24.04 LTS x86_64** с systemd. Устанавливает Telemt 3.5.17 и Caddy, выпускает HTTPS-сертификат и разворачивает страницу сетевой диагностики NX Edge.

## Перед установкой

- Подготовьте VPS с публичным IPv4 и направьте на него A-запись выделенного поддомена. Если есть AAAA-запись, она должна указывать на рабочий публичный IPv6 этого же сервера.
- Разрешите входящий TCP на порты 80 и 443 в панели VPS и на сервере. Порт 18080 используется только на loopback.
- Для запуска нужны sudo и curl. Используйте новый VPS или сервер со штатным Caddyfile из пакета Ubuntu. При обнаружении существующей настройки Caddy либо Telemt установщик останавливается.

## Установка одной командой

Замените `proxy.example.com` на свой поддомен и выполните на VPS.

```bash
curl -fsSL https://raw.githubusercontent.com/FunTom88/TG_WEB/main/install.sh -o tg-web-install.sh && sudo bash tg-web-install.sh --domain proxy.example.com
```

Когда A-записей несколько, укажите нужный публичный адрес дополнительным параметром `--public-ip`. Выбранный IPv4 должен присутствовать в DNS, а клиенты должны попадать на этот сервер.

В конце установщик выведет персональную ссылку `tg://webproxy`. Откройте её в версии Telegram с поддержкой WEB Proxy, затем проверьте отправку сообщений и загрузку медиа. Ссылка содержит секрет доступа. Копию можно посмотреть на сервере командой `sudo cat /etc/telemt/webproxy.link`.

## Проверка

```bash
systemctl is-active caddy telemt
curl -fsS https://proxy.example.com/health.txt
```

Ожидаемый ответ сайта — `NX_EDGE_OK`. Корневой URL открывает NX Edge, а запросы к `/telegram/web/*` Caddy передаёт в Telemt. HTTP 404 на WEB-маршруте при обычном запросе браузера допустим.

Повторный запуск с теми же настройками выводит существующую ссылку. При ошибке во время первой установки скрипт возвращает исходный Caddyfile и отключает созданную службу Telemt. Пакеты, системный пользователь и каталог состояния могут остаться после отката.

При проблемах проверьте `sudo journalctl -u caddy -u telemt -n 80 --no-pager`. Перед публикацией логов удалите ссылки с секретом.
